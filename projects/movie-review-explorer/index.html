Movie Review Explorer

A Python and Flask web API backed by a SQLite database. It lets you browse movies, search them several ways, and add new movies, actors, and reviews.

How it works

  1. Store. A SQLite database holds four related tables: movies, actors, reviews, and a link table that connects actors to the movies they appear in.
  2. Serve. A Flask app turns SQL queries on that database into web endpoints that return JSON.
  3. Search. Look up movies by part of a title, by actor name, or by minimum average star rating.
  4. Add. Send a POST request to add a movie, an actor (linked to a movie), or a star rating and written review.

Endpoints

  • GET /movies lists every movie with its actors
  • GET /movies/title/<text> finds movies whose title contains the text
  • GET /movies/actors/<name> finds the movies an actor appears in
  • GET /movies/ratings/<min> returns movies with an average rating at or above the minimum
  • POST /movies/new, /actors/new, and /movies/<id>/review/new add new records
