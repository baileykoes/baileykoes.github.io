Movie Review Explorer

A Python project that pulls movie review data from an API, stores it in a SQLite database, and analyzes it to see what the ratings can tell us.

How it works

  1. Collect. A Python script requests movie review data from an API.
  2. Store. The results are saved in a SQLite database so the data can be queried with SQL.
  3. Clean and analyze. Pandas and NumPy prepare the data, and regression models look at how the variables relate to each other.
  4. Visualize. Matplotlib charts make the patterns easy to see.
